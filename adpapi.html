An SDK that started with a birthday reminder

Trinity Ops wanted employees' birthdays and work anniversaries on their supervisors' calendars, with reminder emails to help supervisors celebrate them. I built the entire adpapi SDK to support that workflow. It is still running today.

ADP Workforce Now access meant handling OAuth2 client credentials, mutual TLS certificates, token refresh, and paginated responses. I put those concerns into a reusable client so the next integration would not have to implement them again. The SDK now supports several internal workflows, including calendar sync, deduction auditing, HR email automation, and CRM reconciliation.

One client, reusable query handling

The client handles authentication, retries with exponential backoff, and OData pagination. For endpoints that take identifiers in the path, it can make a batch of requests from a list of IDs. Callers choose the fields and filters they need, with masked or unmasked responses subject to the tenant's permissions.

I built an expression API for composing OData filters in Python. It keeps filter construction readable at the call site while the client handles the request details.

from adpapi import AdpApiClient, AdpCredentials from adpapi.odata_filters import FilterExpression active_since_2020 = ( FilterExpression.field("workers.status").eq("Active") & FilterExpression.field("workers.hireDate").ge("2020-01-01") ) with AdpApiClient(AdpCredentials.from_env()) as api: workers = api.call_endpoint( endpoint="/hr/v2/workers", filters=active_since_2020, select=["workers/person/legalName", "workers/associateOID"], masked=True, )
Adapted from the public README. Field paths are illustrative; supported filters depend on the ADP endpoint.

The same client in services and notebooks

The internal integrations run as Azure Functions and feed data into Microsoft Fabric. I also provide a generated single-notebook version for Fabric and Databricks: running that notebook exposes the client in the session without installing the package into a custom runtime.

The SDK is published on PyPI with documentation and an MIT license. Its scope is Workforce Now. Trinity also uses Workforce Manager, whose integrations are outside this SDK.
