The problem

Power Automate flows that touch Excel run Office Scripts, a sandboxed flavor of TypeScript. Filtering, grouping, merging, and pivoting a table there means hand-written loops over arrays, and there is no package manager to reach for. The automation ends up long, hard to read, and hard to maintain.

What frosts adds

Frosts is a pandas-inspired framework that runs natively in Office Scripts. It gives you a DataFrame-style way to filter, group, merge, and describe datasets entirely inside Excel, so a flow can read like an analysis instead of a pile of loops. The full namespace guide documents every method and its performance.

No imports, so one file

The Office Scripts engine does not support imports. That means frosts ships as a single file that you copy into each script. It works, but a deployed script rarely uses more than a handful of methods, and all the rest is dead weight in a place where compact, readable files matter.

Permafrost

Permafrost is the answer: a small compiler, distributed as a downloadable program, that reads your finished script, keeps only the frosts methods it actually calls, strips the internal comments, and copies the trimmed result to your clipboard, ready to paste into the Office Scripts editor. You double-click it, type the name of your file, and paste.

It currently has builds for Windows and macOS, a Linux build is planned, and it is still in beta. The project asks for a bug report with the compiled output whenever the result is not what you expect.
